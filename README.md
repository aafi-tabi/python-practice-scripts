# Python Practice Scripts

A growing collection of small Python practice scripts covering core logic, strings, conditionals, and simple interactive tools. These were built to practice fundamentals — not polished applications, but a record of consistent practice.

## What's Inside

All scripts live in [`practice-scripts/`](./practice-scripts), covering things like:

- Basic logic and conditionals (grading systems, age checker, tallest-of-N)
- String manipulation (palindrome checker, reverse text, name generator)
- Simple interactive tools (calculator, password generator, math quiz)
- Small themed mini-tools (mood ring, playlist manager, phone book, outfit planner)

## Getting Started

Each script runs directly with Python 3:

```bash
cd practice-scripts
python3 calculator.py
```

## About

This repo reflects ongoing practice — small, focused scripts written to build comfort with Python fundamentals before moving on to larger projects.
